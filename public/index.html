Pengaturan API Key Gemini (BYOK)

Fitur Analisis Chart AI berjalan dengan model Google Gemini 3 Flash menggunakan API key pribadi Anda (Bring Your Own Key).

Cara Mendapatkan API Key Gratis:
  1. Kunjungi Google AI Studio (aistudio.google.com)
  2. Login dengan akun Google Anda
  3. Klik "Create API key" lalu salin kodenya

🔒 Keamanan: API key Anda dienkripsi (AES-256-GCM) di server, tidak pernah dicatat dalam log, dan tidak pernah ditampilkan utuh kembali. Kuota harian diberlakukan untuk membatasi beban pemrosesan gambar chart di server.
