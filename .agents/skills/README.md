# Auto-Cuan Codex Cloud Skills

Project-local Agent Skills for Codex Cloud.

Included groups:
- Superpowers workflow: planning, brainstorming, debugging, TDD, plan execution, final verification.
- Caveman: evidence-first engineering and skeptical review.
- UI/frontend: UI UX Pro Max and frontend design.
- Review/security: code review, secure coding guidance, best practices, and threat modeling.

These are compact, self-contained Auto-Cuan Cloud editions. They intentionally avoid large upstream data/script bundles and tool-specific assumptions that are not guaranteed inside a Codex Cloud task. The full local skill repositories can remain installed outside this repository.

Codex discovers these project skills from `.agents/skills/<skill-name>/SKILL.md` on branches that contain them.
