# Skill Pack Sources

This project-local Cloud pack is adapted for Auto-Cuan rather than copied verbatim from upstream packages.

Primary inspiration/reference projects:
- Superpowers: `obra/superpowers`
- Caveman: `JuliusBrussee/caveman`
- UI/UX Pro Max: `nextlevelbuilder/ui-ux-pro-max-skill`
- Frontend design patterns: Anthropic official Claude plugin ecosystem
- Security/review patterns: OpenAI skills and Auto-Cuan repository safety requirements

The compact Cloud editions are intentionally self-contained so Codex Cloud does not depend on files installed on the user's Windows D: drive.
